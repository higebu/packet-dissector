# packet-dissector-map

MAP (3GPP TS 29.002, Mobile Application Part) dissector for packet-dissector

This crate is part of the [`packet-dissector`](https://crates.io/crates/packet-dissector)
ecosystem. It is used automatically when you enable the `map` feature flag
on the main crate:

```toml
[dependencies]
packet-dissector = { version = "0.1", features = ["map"] }
```

You generally do not need to depend on this crate directly.

# packet-dissector-per

ASN.1 ALIGNED PER (ITU-T X.691) reader shared by the 3GPP application
protocol dissectors (S1AP, NGAP) of packet-dissector.

This crate is part of the [`packet-dissector`](https://crates.io/crates/packet-dissector)
ecosystem. It is pulled in automatically by the `s1ap` and `ngap` feature
flags on the main crate.

You generally do not need to depend on this crate directly.
